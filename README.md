# RAPIDITO---Tiempo-Reacción- Lista de preguntas
## ¿Cual es la finalidad?
 La finalidad es que el proyecto el profesor pueda dar clase para microcontroladores, saber usar utilizar los timers.
## A que clase de estimulo? 
 dos tipos de estimulo, auditivo y visual en el mismo modulo. Medir el tiempo entre el estimulo y la reaccion como objetivo central.
## Como se mide la reacción?
Implementar método de detección de inicio de acción y paro de acción de reacción. Opciones múltiples, desde botones, leds, buzzers y demas.
## ¿Qué hará con la reacción?
Mostrar la cantidad de tiempo de reacción en microsegundos y el método de visualización será a través de una APP.
## - tolerancia
Variable segun el microcontrolador utilizado. Implementar un mecanismo para acortar el tiempo de CPU. 
Nota: evaluar uso del osciloscopio. 
## - rango de medición
 Variable según el individuo de estudio. Milisegundos o segundos 
## - Cual es el critetio de evaluación?
 Bajo investigación, aspectos médicos/físicos a investigar.
